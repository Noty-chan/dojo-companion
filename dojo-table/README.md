# Стол «Паника в Додзе»

Упрощённый виртуальный стол под Panic at the Dojo — спутник [цифрового компаньона](../dojo-character-builder/):
персонажи, пачки и сцены **импортируются из компаньона** (JSON или PNG-карточки с зашитыми данными),
а не создаются заново. Архитектура и контракт форматов — в `../dojo-character-builder/docs/vtt-план.md`.

## Запуск

- Дважды кликнуть `Запустить стол.cmd` (порт 5181), остановить — `Остановить стол.cmd`.
- Или из терминала: `npm install` (один раз), затем `npm run dev`.

## Что умеет (этапы 1–4 плана)

- **Инициатива по правилам PatD** (раздел «Шкала инициативы»): «Начать бой» собирает шкалу —
  ячеек = числу шкал здоровья, первым ходит герой, дальше стороны строго чередуются. У фишки
  есть поле «шкалы здоровья» = число ходов за раунд (босс с 4 шкалами делает 4 хода). На текущей
  ячейке активная сторона выбирает, кто берёт ход; активная фишка подсвечена на поле золотым кольцом
  и открыта в панели. Показывается чек-лист из 8 фаз хода (в 1-й ход боя фаза выбора стойки — пропуск).
  «Следующий ход» сбрасывает всем жетоны скорости (правило конца хода) и двигает шкалу; на последней
  ячейке начинается новый раунд (возвраты + обновление «раз в раунд»). Всё синхронно в комнате.


- **Комнаты с живой синхронизацией** (Supabase Realtime, проект прошит в приложение):
  «Создать комнату» → продиктовать 5-значный код игрокам → все видят один стол и меняют его.
  Индикатор связи и число участников в шапке; без комнаты стол работает полностью офлайн.
- **Арена**: квадратные **и гексовые** сетки, размер до 20×20, счётчик раундов,
  состояние переживает F5 (localStorage + строка комнаты в базе).
- **Фон арены** (для ГМа): загрузка карты (ужимается и уезжает в Supabase Storage),
  подгонка масштабом/сдвигом/прозрачностью, «Вписать в поле», обрезка краями поля.
- **Фишки**: герои и враги, перетаскивание со снапом, HP-пилюля и щит на фишке;
  **ГМ может скрывать фишки** — игроки их не видят, ГМ видит полупрозрачными (глаз в панели).
- **Инструменты**: линейка (дистанция в клетках — Чебышев на квадратах, кубовая на гексах,
  видна всем в комнате), пинг точки (мигает у всех), временные рисунки от руки (+ «стереть всё»),
  террейн-кисть на тайлах C0rked (8 типов) и ластик.
- **Импорт из компаньона**: перетащить JSON/PNG героя, пачки, врага или сцены.
  Враг с «количество: N» высаживается N фишками; сцена переименовывает арену.
- **Панель фишки**: HP/щит/броня, жетоны PatD; у героев — стойки с бросками пулов костей форм.
- **Дайс-трей**: последние броски лежат костями, каждую можно кликом пометить потраченной
  (механика спенда PatD); лог событий; опционально дублируется в Discord-вебхук.

## Что дальше (этап 5)

«Спенд» костей с привязкой к действиям стойки, параметры боя из сцены, суперприёмы, таймер хода.
См. план в компаньоне.

## Технически

- Vite + React 19 + TypeScript, без бэкенда; `npm run build` — статика в `dist/`.
- `src/companionTypes.ts` — копия `types.ts` компаньона (общий контракт данных, синхронизировать при изменениях).
- `npm run sync:data` — подтягивает свежий `builder-data.json` из компаньона (делается автоматически при сборке).
- Тесты: `npm test` (парсер костей, импортёры).
