# Паника в Додзе: цифровой компаньон

Внешний офлайн-компаньон для русской версии Panic at the Dojo. Сейчас ядро приложения — сборка
героя, библиотека форм/стилей/архетипов, справочник правил, мастерская сцен/врагов,
медиатека и переносимые экспорты. Дальше сюда же переезжают более полные GM-инструменты,
пресеты и будущая связка с отдельным интерактивным столом.

## Запуск

Одной кнопкой: дважды кликнуть `Запустить компаньон.cmd`. Он поднимет локальный сервер и откроет браузер на `http://127.0.0.1:5180/`.

Остановить сервер: `Остановить компаньон.cmd`.

Ручной запуск для разработки:

```powershell
npm install
npm run browsers:install
npm run dev -- --port 5177
```

Открыть: `http://127.0.0.1:5177`

## Сборка для распространения

```powershell
npm run build
```

Перед сборкой автоматически запускается `npm run generate:data`, поэтому `public/data/builder-data.json` пересобирается из актуальных файлов перевода. Готовая статическая версия появляется в `dist/`. Её можно выложить на GitHub Pages/itch.io или упаковать в архив.

## Локальная QA

```powershell
npm run qa:portable
```

Команда использует проектный Chromium из `.ms-playwright/`, экспортирует PNG-карточку героя,
импортирует её обратно и проверяет загрузку обычной картинки в медиатеку. Если Chromium ещё не
установлен, сначала выполните `npm run browsers:install`.

## Обновление данных после правок перевода

```powershell
npm run generate:data
```

Перед сборкой `npm run generate:data` сначала запускает `npm run generate:reference`.
Справочник пересобирается из `../Паника в Додзе (перевод, редактируемый).docx` в
`../data/companion_reference.json`, а затем основной генератор читает `../data/forms_patched.json`,
`../data/companion_reference.json`, `../_ru_ch5.txt` и `../_translation_full.txt`.
После этого применяются стабильные id, английские названия и TTS-метаданные из
`data/builder-overrides.json`.

Формы берутся из `../data/forms_patched.json`: там хранятся патчевые кости, роли, альт-названия,
фиолетовые кости, способности, действия и навыки форм. Это тот же источник, который используется
для карточек форм в книге.

Справочник берётся из текущей DOCX-книги и включает Супер-приёмы, развитие, рост врагов,
параметры боя, проверки стойкой, состязания стойками и архетипы злодеев.

## Текущие экспорты

- `TTS-объект для стола` — готовый Tabletop Simulator **Saved Object** (`*.SavedObject.json`). Внутри по одной карте на каждый элемент билда: где элемент привязан к реальной карте игры (см. `builder-overrides.json`), подставляется настоящая картинка карты с её FaceURL; остальные элементы выходят карточками-заглушками с рубашкой PatD, а весь текст правил лежит в описании карты (наведение мышью в игре). Первая карта `★ Имя` в описании содержит сводку всего билда.
- `Лист для печати (HTML)` — самодостаточный HTML-лист персонажа: открыть на телефоне у стола или распечатать.
- `Большая PNG-картинка` — лист персонажа одной картинкой (динамическая высота), для чата или печати.
- `JSON персонажа` — основной переносимый формат билда (импортируется обратно кнопкой загрузки).
- `PNG-карточка героя/врага/сцены` — короткая картинка с зашитыми JSON-данными. При загрузке обратно приложение восстанавливает соответствующий билд, врага или сцену.
- Обычные PNG/JPEG/WebP, загруженные через экран `Экспорт / импорт`, сохраняются в медиатеку.

### Куда класть TTS-объект

Скачанный `*.SavedObject.json` положить в
`Документы/My Games/Tabletop Simulator/Saves/Saved Objects/`, затем заспавнить из внутриигрового меню объектов.

### Карты с настоящими картинками

`faceUrl`/`backUrl`/`deckId`/`cardId` реальных карт хранятся в `data/builder-overrides.json` (раздел `tts`)
и один раз были разрешены из стола `TS_AutoSave_3.json`. Сейчас привязаны 14 элементов (Наставник со
стилями/статями + базовые формы). Чтобы добавить ещё карт, допишите `tts` нужным элементам в overrides
и пересоберите данные (`npm run generate:data`).

## Данные

Основной источник для приложения: `public/data/builder-data.json`.

`src/data/seedData.ts` остаётся аварийным fallback, если JSON не загрузился. Сейчас генератор выпускает 108 элементов: 13 архетипов, 12 форм, 65 стилей, 6 статей и 12 навыков.
